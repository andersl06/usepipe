Como criar o link do WhatsApp em quatro passos

O formato do link é fixo e público. Quem erra, erra sempre no mesmo lugar: o formato do número.

  1. 1

    Escreva o número no formato internacional

    Código do país, DDD e número, tudo junto e só com dígitos. O celular (11) 99999-8888 vira 5511999998888. Sem o sinal de mais, sem o zero do DDD, sem parêntese e sem traço.

  2. 2

    Escolha a mensagem que já vem digitada

    A mensagem entra depois de ?text= e precisa estar codificada para URL. Espaço vira %20 e acento vira sequência com %. O gerador acima faz essa conversão enquanto você digita, então escreva normal.

  3. 3

    Teste no celular e no computador antes de publicar

    Clique no botão Abrir conversa nos dois aparelhos. No computador o link abre o WhatsApp Web ou o aplicativo de desktop; no celular abre o aplicativo direto. Se aparecer aviso de número inválido, o problema está no passo 1.

  4. 4

    Publique no lugar onde o cliente já está

    Bio do Instagram, botão fixo do site, assinatura de e-mail, ficha do Google Empresas e QR code impresso no balcão. Um link só, usado em todos esses lugares, vira um número só para medir depois.

Como mandar mensagem no WhatsApp sem salvar o contato

É a mesma função. Quando você abre um link wa.me, o WhatsApp abre a conversa com aquele número sem adicionar ninguém à sua agenda. Serve para responder um cliente que ligou uma vez, para falar com um fornecedor pontual e para não encher o celular de contato morto.

No celular, Android ou iPhone

  1. Preencha o número no gerador desta página.
  2. Toque em Abrir conversa.
  3. O WhatsApp abre a conversa. Mande a mensagem normalmente.

A conversa fica no seu histórico com o número aparecendo no lugar do nome. Nenhum contato novo é criado na agenda do aparelho.

No computador, pelo WhatsApp Web

  1. Deixe o WhatsApp Web conectado ao celular.
  2. Gere o link aqui e clique em Abrir conversa.
  3. A conversa abre em uma aba nova, com a mensagem já escrita.

Se a sessão do WhatsApp Web tiver caído, o link mostra a tela do QR code de login antes de abrir a conversa. Reconecte e clique de novo.

Não instale aplicativo de terceiros para isso. Existem dezenas de apps de "mensagem sem salvar contato" que pedem acesso à sua conta do WhatsApp. Eles usam versões modificadas do aplicativo, que é justamente o comportamento que mais derruba número. O link wa.me é o recurso oficial e não pede permissão nenhuma. Entenda o que realmente derruba um número.

Os formatos de link que o WhatsApp aceita

Quatro endereços diferentes, com finalidades diferentes. Os dois primeiros fazem exatamente a mesma coisa.

O wa.me e o api.whatsapp.com são endereços do próprio WhatsApp e apenas abrem o aplicativo. Nenhum dos dois usa a API oficial do WhatsApp Business, apesar do nome do segundo.
FormatoExemploQuando usar
Link curto wa.me/5511999998888 O padrão. Abre a conversa sem mensagem pronta.
Link curto com mensagem wa.me/5511999998888?text=Ol%C3%A1 Quando você quer que o cliente já chegue dizendo o assunto.
Link longo api.whatsapp.com/send?phone=5511999998888&text=Ol%C3%A1 Quando um sistema de terceiros exige parâmetros nomeados.
Link do WhatsApp Business wa.me/message/XXXXXXXXXX Gerado dentro do app Business, em Ferramentas comerciais. Esconde o número.

Os cinco erros que fazem o link não abrir

Praticamente todo link quebrado cai em um destes casos.

Onde colocar o link para ele render

O link é o mesmo. O que muda é o formato de quem recebe.

Bio do Instagram e do TikTok

Cole o link wa.me direto no campo de site do perfil. Escreva a chamada na bio dizendo o que a pessoa recebe ao clicar, porque link sem promessa não é clicado.

Botão fixo no site

Use o código gerado acima. Um botão flutuante no canto da tela costuma render mais contato que um botão no rodapé, porque acompanha a rolagem.

QR code impresso

Balcão, cardápio, embalagem, adesivo de vitrine e crachá de vendedor. Baixe o SVG, que não borra em nenhum tamanho de impressão.

Precisa só do QR code, sem o resto? Use o gerador de QR code do WhatsApp, que entrega os arquivos prontos para impressão em uma tela só.

Perguntas frequentes

Dúvidas sobre o link do WhatsApp

Como criar um link do WhatsApp com mensagem pronta?

O formato é https://wa.me/DDIDDDNUMERO?text=MENSAGEM. Para o número (11) 99999-8888 no Brasil, o link fica https://wa.me/5511999998888?text=Ol%C3%A1. O texto precisa estar codificado para URL, ou seja, espaço vira %20 e acento vira uma sequência começada por %. O gerador desta página faz essa codificação sozinho enquanto você digita.

Como mandar mensagem no WhatsApp sem salvar o contato?

Gere o link wa.me com o número da pessoa e abra esse link. O WhatsApp abre a conversa direto, sem que o número entre na sua agenda. Funciona no celular Android, no iPhone e no WhatsApp Web. É o mesmo recurso oficial usado pelo botão de WhatsApp dos sites, então não exige aplicativo de terceiros nem permissão extra.

Preciso colocar o 55 antes do número?

Sim. O link wa.me exige o número no formato internacional, com o código do país na frente e sem sinal de mais, sem zero, sem parêntese e sem traço. Para o Brasil o código é 55, então (11) 99999-8888 vira 5511999998888. O erro mais comum é manter o zero do DDD, o que faz o WhatsApp responder que o número é inválido.

O link do WhatsApp funciona no computador?

Funciona. No computador o link wa.me abre o WhatsApp Web ou o aplicativo de desktop, dependendo do que estiver instalado, e a mensagem aparece pré-preenchida do mesmo jeito. Se você usa o WhatsApp Web, precisa estar com a sessão conectada ao celular antes de clicar.

Quantos caracteres a mensagem do link aceita?

Na prática, links com até 1.000 caracteres de mensagem abrem sem problema em todos os navegadores. Acima disso alguns navegadores e aplicativos de terceiros cortam a URL, porque o limite não é do WhatsApp e sim do tamanho de link que cada programa aceita. Como regra de operação, mensagem de primeiro contato com 2 a 4 linhas converte mais do que texto longo.

O link do WhatsApp pode fazer meu número ser banido?

O link em si não. Ele é um recurso oficial e é a própria Meta que documenta o formato wa.me. O que causa banimento é o comportamento depois: mandar mensagem em massa para quem não pediu, usar aplicativo modificado ou disparar de um número novo sem histórico. Quando o cliente é quem clica no link e inicia a conversa, o risco é baixo, porque a Meta trata isso como contato solicitado.

Qual a diferença entre wa.me e api.whatsapp.com/send?

As duas fazem a mesma coisa. O wa.me é a versão curta e é a recomendada para material impresso e para bio de rede social. O api.whatsapp.com/send?phone=&text= é a versão longa, útil quando algum sistema de terceiros exige parâmetros nomeados. Nenhuma das duas usa a API oficial do WhatsApp Business, apesar do nome; as duas apenas abrem o aplicativo.

Dá para gerar um link do WhatsApp para grupo?

O link de grupo não é gerado por fora. Ele sai de dentro do próprio grupo, em Dados do grupo, Convidar via link, e tem o formato chat.whatsapp.com. O link wa.me desta página é para conversa individual com um número, que é o caso de atendimento e de venda.

Depois do primeiro clique

O link traz a conversa. Depois disso, alguém precisa cuidar dela.

Um link resolve o primeiro contato. Com cinco vendedores usando o mesmo número, ninguém sabe quem respondeu o quê, e o histórico do cliente some junto com o celular de quem saiu da empresa. O Pipe atende pela API oficial, guarda cada conversa e cadastra o cliente no CRM a partir dela.
