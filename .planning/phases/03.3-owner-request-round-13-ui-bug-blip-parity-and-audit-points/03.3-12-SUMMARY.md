# Phase 03.3 Plan 12: Pipe Chat Embed and Config Page Summary

An admin can create the Pipe Chat widget channel from the bot's channels page, link it, set allowed origins and greeting, copy a one-line script snippet, and visitors chat through a Shadow DOM launcher/panel that polls the API from plan 11.

Commit: `e6cc403c` feat(03.3-P06): pipe chat embed and config page (single commit for both tasks, as the plan specifies).

## What was built

- `public/pipe-chat.js`: IIFE, no dependencies; Shadow DOM with `pc-` classes only inside the bundle; `textContent` only for message data; every fetch `credentials: 'omit'`; session reuse via `localStorage` `pipe-chat:<key>`; poll 3 s open / 15 s closed; offline banner with "Tentar novamente" after 3 consecutive errors; Esc closes and returns focus to the launcher; full-screen panel under 480px; double-load guard; single `console.warn` without `data-key`.
- Config page `channels/pipe-chat` (CSS prefix `pcc-`): create then link, link-only notice, origins textarea with inline invalid list, greeting (200 chars), save, read-only snippet with copy, "Gerar nova chave" behind ConfirmModal, error state with retry.
- `regras.ts`: pure `parseOrigins` and `pipeChatSnippet` (escapes `& " < >`).
- Channels card: no longer unconditionally connected; Connected only for an active `widget` channel linked to the bot; card links to `channels/pipe-chat`.
