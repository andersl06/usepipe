# Phase 03.3 — Validation Strategy

> Per-phase validation contract. Per-point test detail lives in `03.3-RESEARCH.md` → "Validation Architecture"; the planner fills the per-task map below.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest (API/core, real Postgres 5433 + Redis) and `node --import tsx --test` (management-vite pure logic) |
| **Config file** | existing per-package configs |
| **Quick run command (API)** | `pnpm --filter @pipe/api exec vitest run tests/<file>.test.ts` |
| **Quick run command (UI)** | `pnpm --filter @pipe/management-vite exec node --import tsx --test tests/<file>.test.ts` |
| **Full suite command** | `pnpm test` (after `pnpm --filter @pipe/core build && pnpm --filter @pipe/contracts build`); API in groups (see plan 14) |
| **Estimated runtime** | ~120 seconds per group |

## Sampling Rate

- **After every task commit:** quick run of the touched package test file
- **After every plan wave:** full suite for touched packages + `tsc` typecheck
- **Before verify-work:** full suite green
- **Max feedback latency:** 120 seconds
