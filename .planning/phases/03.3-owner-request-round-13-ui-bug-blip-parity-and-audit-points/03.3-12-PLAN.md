<objective>
P06 part 2 of 2 (embed + config page): the browser side of Pipe Chat on top of plan 11's API. Commit `feat(03.3-P06): pipe chat embed and config page` (second P06 commit, see plan 11 note).

Design:
- Embed: a single hand-written vanilla JS file at apps/management-vite/public/pipe-chat.js (Vite copies public/ as-is, so it is served at `<management origin>/pipe-chat.js`; no build step, no dependency). Snippet: `<script src="<origin>/pipe-chat.js" data-key="<widgetKey>" async></script>`. The script derives the API base from `new URL(document.currentScript.src).origin` (management app proxies /v1 to the API in dev and serves it same-origin in prod), stores `{ visitorId, token }` in localStorage under `pipe-chat:<key>`, creates a host element with `attachShadow({ mode: 'open' })` and injects a `<style>` with `pc-` classes inside the shadow root only. Messages render with `textContent` only (never innerHTML for message data). Polling: every 3 s while the panel is open, every 15 s while closed, stop after 3 consecutive errors and show the offline banner with "Tentar novamente". All fetches use `credentials: 'omit'`.
- Config page: route `channels/pipe-chat` under the bot (same place as instagram/messenger pages) using @pipe/ui components and the shared Select; loads GET /v1/management/widget-channels, creates one on first use (POST), links it to the bot via the existing connect-channel endpoint used by the other channel pages (grep `connectChannelToFlow` callers in apps/api/src/controllers to find the route), edits allowedOrigins (textarea, one origin per line) and greeting (PATCH), shows the snippet with a copy button (navigator.clipboard.writeText) and a "Rotate key" action behind ConfirmModal.

Recommended executor: Sonnet (UI).

No npm installs.
