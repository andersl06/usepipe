# Phase 03.3 - UI Design Contract

> Compact contract. Phase is bug fixes and Blip parity on existing screens in `apps/management-vite`. Rule 1: reuse existing tokens/components; where Blip's real layout (from `referencias-blip`, per the investigation-first decision) conflicts with this file, Blip wins and the findings doc records it. Sources: 03.3-CONTEXT.md, 03.3-OWNER-REQUEST.md, `src/estilos/global.css`.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (custom CSS design system; shadcn gate not applicable, no `components.json`, no Tailwind) |
| Preset | not applicable |
| Component library | none; in-house components in `src/components` (shared `Select`, `card-config`, `estados-tabela`, `panel-filters`, `filters-quick`, `lista-history`, `metrica`) |
| Icon library | in-house `src/components/icones-management.tsx` (keep own icons; add new ones there, no new icon dependency) |
| Font | inherited from `global.css` (do not change) |
| Styling | global CSS in `src/estilos/global.css` using tokens `--ground/--surface/--surface-2/--surface-3/--line/--ink/--ink-2/--ink-3/--moss/--terracotta/--ochre/--online` and `--g-*` sizes |

Rules for every plan:
- No new global class may reuse a prefix already defined elsewhere (`bl-`, `cf-`, `ct-` are shared and colliding). New UI uses its own prefix: `os-` (org switcher), `tm-` (team members), `pc-` (Pipe Chat widget), `mt-` (message template), `lg-` (logs), `gw-` (Growth cards). Check with grep before adding.
- Selects: always the shared `Select`; inside boxed wrappers it renders bare. Never restyle with page-local select CSS.
- Tooltips on icon buttons must not be clipped: no `overflow:hidden` on the containing cell/card (fixed pattern from monitoring actions cell).

## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact spacing, list row gap, chip padding |
| md | 16px | Default padding, card inner padding (matches `--g-r-card: 16px` radius) |
| lg | 24px | Section padding, widget panel padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: icon-only buttons keep a 32px hit area minimum (44px on Pipe Chat launcher); existing fixed layout vars (`--g-barra-sup-h` 80px, `--g-barra-inf-h` 56px, `--g-lateral-w` 262px) are untouched.

## Typography

Reuse existing `--g-t-*` tokens; no new sizes. Sizes in use: exactly 4 (12, 14, 16, 24). Weights in use: exactly 2 (400, 600). Active tab and report block title use 600 in this contract. Pre-existing weights 700 and 300 (top module) on existing Blip-parity elements are NOT part of this phase's contract and are left untouched; new or reworked UI never uses them.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / table cell / list item | 14px (`--g-t-celula`) | 400 | 1.5 (21px, `--g-lh-card`) |
| Label / helper / timestamp | 12px (`--g-t-rotulo`) | 400 | 18px (`--g-lh-rotulo`) |
| Heading (block, modal, widget header, column header) | 16px (`--g-t-block`) / 14px column | 600 | 24px (`--g-lh-block`) |
| Display (screen title) | 24px (`--g-t-titulo`) | 400 | 1.2 |

## Color

Existing tokens only (60/30/10).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--ground` / `--surface` | Page background, cards, tables |
| Secondary (30%) | `--surface-2` / `--surface-3`, borders `--line` | Dropdown panels, list hover rows, widget message bubbles (received), filter bars |
| Accent (10%) | `--moss` (`--g-barra-marca`), soft `--moss-soft` | See reserved list |
| Destructive | `--terracotta` / `--terracotta-soft` | Remove team member, failed/error states only |
| Warning | `--ochre` / `--ochre-soft` | Window-expired / template-not-approved notices in Growth Active Messages |
| Status ok | `--online` | Connected channel dot, delivered/active badges |

Accent reserved for: active org in the org switcher (check mark + `--moss-soft` row), primary action button of each new panel (Add member, Apply filters, Send message), Pipe Chat launcher and sent-message bubble, selected row/tab indicator. Never for all links or icons.

## Component Contracts (new or reworked UI only)

1. **Org switcher** (`pt-account` summary dropdown, point 2)
   - Trigger: existing account summary; opens a panel (`--surface`, 1px `--line`, radius 16px, shadow `--shadow`, min-width 280px, max-height 320px scroll).
   - Rows (40px high): org name (14/400) + role (12/400, `--ink-2`); active org shows `--moss-soft` background + check.
   - States: loading (3 skeleton rows), single org (list of one, no switch action), error (inline `--terracotta` text + Try again). Selecting an org navigates to that org's portal and closes the panel; Esc and outside click close; keyboard: arrow keys move, Enter selects, focus returns to trigger.
   - "Blip portal" link only if the investigation proves the person has Blip access; otherwise omitted.
2. **Team members** (`application/detail`, point 3)
   - Replaces the "coming soon" placeholder. Table via existing `estados-tabela`: columns Name, E-mail, Role, Added on, Actions (14px cells, 14/600 headers). Primary button "Add member" opens modal (e-mail + role `Select`). Row action: remove (icon button with tooltip and `aria-label="Remove member {name}"`, confirm modal).
   - Primary focal point: the "Add member" button (top-right of the table header, only accent element on screen).
   - Source of roles/columns follows Blip findings (router, flow, contract differ); columns not proven by findings are dropped.
3. **Pipe Chat widget** (point 6)
   - Launcher: 56px circular `--moss` button, bottom-right, 16px from edges (44px minimum hit area honored). Panel: 360px wide x 520px high (full-screen under 480px viewport), radius 16px, header 16/600 with channel name and close button, message list on `--surface-2`, received bubbles `--surface` , sent bubbles `--moss` with white text, 12px timestamps, composer with 14px input + "Send message" button (disabled when empty).
   - Primary focal point: the message list and composer (panel opens with focus in the composer input).
   - States: connecting (spinner + "Connecting..."), offline/error (`--terracotta-soft` banner + Try again), empty (greeting from channel config). `aria-live="polite"` on message list; launcher has `aria-label="Open chat"`.
   - Widget CSS is scoped under `pc-` and shipped in the embed bundle, never in `global.css`.
4. **Message template page** (`attendance/message-template`, point 13)
   - Layout, columns, filters, status badges, and create/edit flow replicate Blip's page as found in `referencias-blip`; structure comes from the findings doc, tokens from this file. Status badges: approved `--online`, pending `--ochre`, rejected `--terracotta`. Reuse `panel-filters`, `estados-tabela`, shared `Select`.
   - Primary focal point: the status badge column (badges are the only colored elements in the table).
5. **Logs filters** (point 8)
   - Reuse `panel-filters`; fields match Blip's filter set (from findings). Apply button (accent), Clear link. Filter chips 12px, 8px gap. Logs render even when logging is disabled if Blip does, with a 12px `--ink-2` info line "Logging is disabled for this channel" (not a blocker).
6. **Growth cards** (point 5)
   - Every card has the same four states: loading (skeleton), empty, error, populated. Card radius 16px, 16px padding, title 14/600, value 24/600 (reuses the 24px `--g-t-titulo` size), label 12/400. Active Messages shows `--ochre` notice for expired window / unapproved template and blocks Send with the reason.
7. **Conversation history and contacts** (points 7, 9)
   - Contact label in router is the channel identity (e.g. `5521972570484@wa.ms`), flow shows channelId; long values truncate with ellipsis and full value in a tooltip. History entries grouped per ticket with a 12px ticket header (ticket id, status, dates); retention note "Showing the last 90 days" in 12px `--ink-2`. Redirect icon stays inside its card/cell.
