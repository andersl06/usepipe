# 01.1-02 Summary

Allowed origins now combine fixed `PIPE_ORIGENS` entries with exact tenant hosts derived from `PIPE_DOMINIO_CONTAS`. Literal wildcards are ignored. CORS, login origin validation and WebSocket continue to use the same function.

The session and API-key guards compare the request tenant signal with the credential's tenant slug. Session and key queries load that slug with the credential, and return the same `tenant_mismatch` response for any different slug. WebSocket applies the check before upgrade. With no configured tenant domain, no tenant signal is produced.
