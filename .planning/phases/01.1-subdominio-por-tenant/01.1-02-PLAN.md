<objective>
Fazer a API aceitar origens por sufixo de domínio e resolver o tenant pelo Host, recusando credencial de outro tenant no HTTP e no WebSocket.

Purpose: com um subdomínio por cliente, a lista fechada de `PIPE_ORIGENS` vira infinita, e o cookie com `Domain=.<D>` chega a todo subdomínio. O Host passa a ser um segundo sinal de tenant que precisa casar com a credencial. Sem isso, uma sessão do tenant A aberta no host do tenant B carregaria as telas de B com dados de A (Pitfall 2), ou o contrário se algum dia a sessão for resolvida pelo host.
Output: origem por sufixo, guard Host↔credencial, confronto no WS, testes.

Model routing: Sonnet (controle de acesso; nada aqui é mecânico).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Navegador → API (`Origin`, `Host`, cookie `Domain=.<D>`) | o cookie chega em qualquer subdomínio; Host e Origin são do cliente |
| Traefik → API | Traefik repassa o Host; a API não é exposta sem ele |
| Chave de API → API | integração de cliente, pode chegar por host de tenant |
