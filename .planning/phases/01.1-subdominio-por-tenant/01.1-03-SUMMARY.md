# 01.1-03 Summary

Tenant mode now requires a matching session cookie domain and a Google callback on `login.<D>` at API startup. The OAuth challenge cookie remains host-only; the session and logout cookies use the configured parent domain. Google, SSO and development login enter through the central login host. After authentication, a validated `returnTo` is followed only when its slug matches the authenticated tenant; a different slug redirects home with `deniedTenant`.

Invitation links from the API and CRM use `login.<D>`. The SSO callback URL does too. Provisioning rejects reserved system slugs before any database call and prints management, Desk and login URLs for the new tenant. Without `PIPE_DOMINIO_CONTAS`, the existing paths remain active.

## Plan adjustment
