# 01.1-04 Summary

Management now computes its Desk link from the current host and authenticated `tenant.slug`; a mismatched or unrecognized host yields no link. The central login host serves only login and invitation routes. Authenticated users with `returnTo` go to their own tenant or receive the short `deniedTenant` notice; reserved hosts render an address-not-found page without requesting the API. Management and Desk redirect 401 or `tenant_mismatch` from `GET /v1/eu` to central login, preserving the current URL.

Both Vite servers now bind IPv4, allow local subdomain hosts and preserve `Host` through the `/v1` proxy. Browser builds use same-origin `/v1`; the Desk build argument and `VITE_PIPE_DESK_URL` were removed. The existing `/` → `/application` redirect was already present.

The old bundle contained fixed support addresses and an account label under an older Pipe domain. Those display links now use the current host or optional `VITE_PIPE_SUPPORT_EMAIL`; when it is unset, the screen directs people to their account administrator. This was needed for the plan's no-domain-literal bundle check.
