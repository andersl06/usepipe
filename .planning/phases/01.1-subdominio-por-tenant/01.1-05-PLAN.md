<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → Traefik (:80/:443) | toda entrada; decide serviço por Host |
| Traefik → Cloudflare API | token que edita a zona |
| Operador → `.env` da VPS | configuração que o deploy valida |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01.1-05-01 | Spoofing | subdomain takeover (registro apontando para serviço de terceiro ou IP liberado) | mitigate | Só registros A para a VPS e CAA; nenhum CNAME para terceiro na zona do cookie; ordem de desmontagem no runbook (plano 08) |
| T-01.1-05-02 | Elevation of privilege | token Cloudflare vazado editando outras zonas/conta | mitigate | Token restrito à zona (DNS Edit + Zone Read); só no serviço traefik; guardado no SOPS |
| T-01.1-05-03 | Spoofing | certificado emitido por outra CA para o domínio | mitigate | CAA `letsencrypt.org` |
| T-01.1-05-04 | Information disclosure | `/metrics` da API exposto por host de tenant | mitigate | `api-tenant` só casa `PathPrefix(/v1)`; `api` mantém `!PathPrefix(/metrics)` |
| T-01.1-05-05 | Spoofing | API alcançada sem Traefik (Host forjado, sem TLS) | mitigate | Só traefik publica portas; checado no verify |
| T-01.1-05-06 | Tampering | regex do Traefik com pontos não escapados | accept | Só amplia casamento de rota; autorização usa parse estrito na API (plano 02); domínio validado no deploy |
| T-01.1-05-07 | Denial of service | rate limit do Let's Encrypt no modo HTTP-01 | accept | Poucos hosts listados (5); modo só de teste |
| T-01.1-05-08 | Spoofing | proxy da Cloudflare terminando TLS e vendo cookie | mitigate | Todos os registros "DNS only"; verify recusa `proxied = true` |
</threat_model>
