## Deviations from Plan

**1. [Rule 1 - Bug] Tokens no `:root`, não logo após `--p-builder-marca-*`.** Aquele bloco fica dentro de `@media (prefers-color-scheme: dark)`. Um token de medida posto ali ficaria indefinido no tema claro. Os 3 tokens foram para o fim do `:root`.

**2. [CLAUDE.md] Comentário sem metadado de fase.** O plano sugeria o comentário `/* Atendimento (03.2, D-11) ... */`. O comentário escrito descreve o papel e cita a fonte, sem número de fase.

**3. Tokens só para o que diverge.** Os nomes que o plano sugeria (`--p-atend-lateral-largura`, `-item-altura`, `-item-padding`, `--p-atend-barra-contato-altura`) não foram criados: essas medidas já batem com a Blip e já são servidas por `--g-lateral-w`, `--g-barra-inf-h` e `--p-e-2`.

**4. Prints com tenant local do dono.** O único tenant local com onboarding concluído e fluxo é o do dono (`anderson---teste`). Os tenants e2e param na tela `/welcome`. Os prints ficaram em `referencias-blip/pipe-capturas/` (ignorado pelo Git).

**5. A API local ignora o `.env` da raiz e sobe na porta 3000.** Para medir, o Vite foi apontado para ela com `PIPE_URL_API=http://127.0.0.1:3000`. Os servidores foram encerrados no fim, e o perfil do Chrome headless foi apagado.
