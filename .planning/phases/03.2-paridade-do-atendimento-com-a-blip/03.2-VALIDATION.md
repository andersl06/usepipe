# Phase 03.2 — Estratégia de Validação

> Contrato de validação por amostragem durante a execução.

## Infraestrutura de teste

| Propriedade | Valor |
|-------------|-------|
| **Framework** | vitest ^3.2.4 (raiz) |
| **Config** | `apps/management-vite/tests/*.test.ts` (lógica pura, sem DOM); API em `apps/api/tests` |
| **Comando rápido** | `pnpm --filter @pipe/management-vite test` (confirmar nome do filtro) |
| **Suíte completa** | `pnpm -r test` + `pnpm --filter @pipe/management-vite typecheck` + `lint` |
| **Runtime estimado** | ~60 s |

## Amostragem

- **Após cada tarefa:** vitest do módulo tocado + typecheck
- **Após cada onda:** suíte completa + medição das telas da onda + portão do dono
- **Antes de `/gsd:verify-work`:** suíte verde + GATE-FINAL
- **Latência máxima:** 120 s
