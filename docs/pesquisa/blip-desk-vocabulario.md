## Observações Importantes

1. **blip-ticket-metadata**: Apenas 3 textos únicos encontrados. O arquivo é pequeno (12 KB) e provavelmente é um micro-frontend simples de renderização de metadados sem muita interface dinâmica.

2. **Limpeza de ruído**: A extração de `app.js` e alguns módulos incluiu ruído de minificação (palavras-chave de código, fragmentos de strings que não são interface). Os resultados foram filtrados para remover artifacts óbvios.

3. **Padrão de português**: O regex usado procura por características de português (terminações `-ção`, `-ções`, `-ário`, `-ência`, além de palavras-chave comuns como "não", "já", "cliente", "contato", etc).

4. **Limitação**: A maioria das seções foi limitada a 60 itens por apresentação conforme solicitado. Alguns módulos naturalmente geraram listas menores.

5. **Não confirmado**: 
   - `blip-ticket-metadata` tem apenas 3 itens — o arquivo é muito pequeno e pode ser apenas renderização.
   - Alguns textos em `app.js` podem ser mensagens de error de framework ou warnings minificados.
